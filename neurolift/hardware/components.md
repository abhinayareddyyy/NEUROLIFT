# Hardware Components - Neurolift

## Components Used

### Arduino Uno
Main microcontroller used for sensor processing and servo control.

### MPU6050
Detects foot angle and movement using accelerometer and gyroscope data.

### EMG Sensor
Detects muscle activity signals from the leg.

### SG90 Servo Motor
Provides mechanical assistance for foot lifting.

### Jumper Wires
Used for electrical connections between components.

### USB Power Supply
Provides 5V power to the system.

### Wearable Frame
Supports the ankle brace and holds sensors and mechanical mechanism in place.

### Elastic Bands / Strings
Creates mechanical linkage between servo motor and foot.
